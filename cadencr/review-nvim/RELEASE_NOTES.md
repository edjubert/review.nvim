# review.nvim for CadencR 0.1.5

- Include the gemoji copyright/license notice with the bundled Lua emoji catalogue.
- Distribute license and attribution notices for compiled frontend dependencies,
  backend Go modules, the Go toolchain and its vendored standard-library code.
- Require clean exact-source builds and native test evidence for macOS arm64,
  macOS Intel and Linux x86_64 before packaging.
- Produce GitHub build attestations, dependency/toolchain receipts, native test
  logs and exact-source registry metadata from the release workflow.

Requires CadencR 0.16.0+, Neovim 0.11+ and existing Git/provider CLI authentication.
Draft comments remain local until an explicit review.nvim publication command.
The previously published 0.1.4 tag and assets are preserved.
